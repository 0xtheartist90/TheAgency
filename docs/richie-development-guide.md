# Richie's Basic Dev Flow

Keep it simple.

Write your request in normal words.
If helpful, include:
- a screenshot
- what is wrong
- what you want instead

Then paste this at the end of your prompt:

```md
Use superpowers for this task. Help me clarify the request, make a small plan, and review the result after the change.
```

That is the default flow.

Example:

```md
The mobile menu feels broken on the homepage. The spacing looks off and the button is too close to the logo. Screenshot attached.

Use superpowers for this task. Help me clarify the request, make a small plan, and review the result after the change.
```

If Richie does that every time, that is enough.
